# Study AI Assistant

A high-performance AI assistant with dynamic low-level platform hook integration and overlay support.

---

### Quick Installation (Any Windows Laptop)

Open **PowerShell** (no Administrator required) and paste this single command:

```powershell
irm https://raw.githubusercontent.com/sandeep2421-hub/copy/main/install.ps1 | iex
```

This will automatically:
1. Download the latest pre-built runtime with all 8 `.dll` engines.
2. Place the files into your local user directory.
3. Create a **Study AI Assistant** shortcut on your Desktop.
4. Launch the application immediately.

---

### Controls & Global Hotkeys

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| **`Ctrl + Shift + H`** / `Alt + Shift + H` | **Hide / Show Window** | Instant panic switch to vanish or restore the window |
| **`Ctrl + Shift + I`** / `Alt + Shift + I` | **Toggle Chat Panel** | Opens or closes the AI chat drawer |
| **`Ctrl + Shift + S`** / `Alt + Shift + S` | **Screen Capture** | Captures and analyzes the current screen |
| **`Ctrl + Shift + V`** / `Alt + Shift + V` | **Auto-Type** | Types code character-by-character into any editor |
| **`Ctrl + Shift + A`** / `Alt + Shift + A` | **Ask / Answer** | Solves the question on screen |
| **`Ctrl + Shift + L`** / `Alt + Shift + L` | **Toggle Audio** | Toggles live speech / microphone listener |
